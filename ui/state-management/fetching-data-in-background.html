In modern web applications, it's common to fetch data in the background to keep the UI responsive and up-to-date. This can be achieved using various techniques such as polling, WebSockets, or server-sent events.

What's Happening?

In the example above, we have two containers that fetch data from an API. The first container fetches data without using any state management, while the second container uses a state management approach to store and update the fetched data.

Steps:

  1. Create a state container to hold the fetched data.
  2. Use an effect or middleware to fetch data from the API.
  3. Update the state container with the fetched data.
  4. Use selectors to access and display the data in the UI.
